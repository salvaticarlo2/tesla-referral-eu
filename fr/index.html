Comment utiliser le code de parrainage Tesla en France

Trois étapes simples. Le lien de parrainage doit être utilisé avant de configurer votre véhicule — vous ne pourrez pas l'ajouter après la commande.

01

Ouvrir le lien de parrainage

Accédez à tesla.com/referral/carlo719460. Cela ouvre directement le configurateur Tesla français avec le code de parrainage déjà appliqué. Ne commencez pas depuis la page d'accueil tesla.com/fr_FR — le code ne sera pas appliqué.

02

Configurer votre Tesla

Choisissez votre modèle (Model 3, Model Y, Model S ou Model X), couleur, jantes et intérieur. L'avantage de parrainage apparaît dans le récapitulatif de commande — Supercharge gratuite ou crédits Tesla selon le modèle. Si vous n'êtes pas connecté, créez un compte Tesla.com avec votre adresse email française.

03

Passer votre commande

Finalisez votre commande normalement. Les avantages ne s'appliquent qu'avec un parrainage actif et sont en général crédités à la livraison. L'aide à l'achat (prime « Coup de pouce » CEE) se demande séparément : vérifiez la démarche actuelle sur economie.gouv.fr.

Aide à l'achat + parrainage Tesla : peut-on les cumuler ?

Bonne nouvelle : oui, les deux sont cumulables. Voici comment maximiser vos économies sur votre Tesla en France en 2026.

✓ Deux dispositifs indépendants : un parrainage Tesla actif et l'aide de l'État à l'achat d'un véhicule électrique ne s'excluent pas. Le quota 2026 du code de ce site est toutefois épuisé.

Depuis le 1er juillet 2025, l'ancien Bonus Écologique est remplacé par la prime « Coup de pouce véhicules particuliers électriques », financée par les certificats d'économies d'énergie (CEE) et versée via les fournisseurs d'énergie. Le montant dépend des revenus du ménage et peut changer en cours d'année, c'est pourquoi nous n'affichons pas de chiffres ici.

  • Model Y (produit à Berlin) : éligible à la prime principale, sous conditions de ressources.
  • Model 3 (produit à Shanghai) : pas éligible à la prime principale, car il n'atteint pas le score environnemental minimum de l'ADEME.

Vérifiez les montants et la démarche actuels sur economie.gouv.fr avant de commander. Un parrainage, lui, s'applique uniquement via un lien actif au moment de la commande sur tesla.com.

Dernière vérification de l'éligibilité : octobre 2026. Les conditions de la prime évoluent : la source officielle fait foi.

Questions fréquentes — Code Parrainage Tesla France

Que puis-je obtenir avec le code carlo719460 en France ?

Le quota 2026 de ce code est épuisé, il ne donne donc pas d'avantage pour le moment. Avec un parrainage actif, les avantages varient selon le pays, le modèle et la date : vérifiez-les dans l'application Tesla ou le configurateur.

Le parrainage est-il cumulable avec l'aide à l'achat (ex-Bonus Écologique) ?

Oui. Un parrainage actif s'applique lors de la commande sur tesla.com, et l'aide à l'achat se demande séparément. Depuis juillet 2025, le Bonus Écologique est remplacé par la prime « Coup de pouce » CEE : le Model Y (Berlin) est éligible, le Model 3 (Shanghai) ne l'est pas pour la prime principale. Vérifiez votre éligibilité sur economie.gouv.fr.

Puis-je ajouter le code après avoir passé la commande ?

Non. Vous devez utiliser le lien de parrainage avant de configurer votre véhicule. L'application rétroactive est impossible — c'est une limitation du système Tesla.

Le code est-il valable pour tous les modèles Tesla en France ?

Oui, le code carlo719460 est valable pour Model 3, Model Y, Model S et Model X commandés en France. Les avantages varient : Supercharge pour les modèles accessibles, crédits Tesla pour les premiums. Tesla a arrêté la production des Model S et Model X au deuxième trimestre 2026 : stocks limités.

Quel est le prix du Tesla Model 3 Standard en France ?

En mars 2026, le Tesla Model 3 Standard Range était affiché à partir de €38 990 TTC en France. Vérifiez le prix actuel sur tesla.com/fr_fr. Attention : produit à Shanghai, il n'est pas éligible à la prime principale « Coup de pouce » CEE. C'est le Tesla le plus abordable de la gamme française.
